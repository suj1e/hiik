# Program marks

The SVGs in this folder identify the programs and agents listed in
`programs.json`. They are the projects' own brand marks, used only to label
that program in the interface; this repository grants no license to them and
implies no affiliation. Any mark remains the trademark of its project.

If a mark is wrong, outdated or should not be shipped, replace or remove its
SVG and its `programs.json` entry in the same change. Prefer a project's
published brand asset and record the source in the pull request.
